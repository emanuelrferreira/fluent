# Fluent — Language Practice with Real People

Peer-to-peer language exchange platform. NCI final year project.

## Stack
- Frontend: React.js + Vite
- Backend: Node.js + Express + Socket.io
- Database: MongoDB
- Auth: Firebase Auth
- AI: Google Gemini API (free tier)
- Hosting: Vercel (frontend) + Railway (backend)

## Run locally

### Backend
```bash
cd backend
npm install
cp .env.example .env
node server.js
```

### Frontend
```bash
cd frontend
npm install
npm run dev
```
